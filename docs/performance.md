# 性能验证

本轮优化覆盖原网页、公共排行、店铺资料与 3D 角色资源。页面和游戏规则保持原有行为，支付、余额、登录和权限不使用公共数据缓存。

## 可复现基准

使用 Go 1.27、Apple M5，本地单进程、541 个合成站点和 5,400 笔合成记录。结果为预热后测量，不包含网络、CDN、首轮编译或手机 GPU 性能，也不是满员容量承诺。

| 基准 | 优化前 | 优化后 |
|---|---:|---:|
| 三类公共榜单及职位读取 | 22.01 ms | 0.098 ms |
| 完整首页渲染 | 20.27 ms | 4.89 ms |
| 店铺目录响应生成 | 0.242 ms | 0.034 ms |
| 首页每请求分配 | 3.59 MB | 0.88 MB |

```bash
go test -run '^$' -bench 'BenchmarkPublicRanks|BenchmarkHomePage|BenchmarkWorldCatalog' -benchmem -count=1
```

夹具在 `performance_test.go`，使用独立临时数据库；测试不会读取正式配置或数据库。修改实现后应在同一设备、相同数据集下对比，冷缓存、频繁写入或并发请求的结果会不同。

## 资源与渲染

- 原网页公共 CSS 独立打包并按内容哈希缓存，切页不再重复传输整段内联样式。
- 像素画生成器将同色像素合并为 SVG 路径，保留 body、eyes、tear、bowl 等动画层。本轮逐层逐像素校验一致，生成模板由 132,816 字节降至 43,286 字节，绘图节点由 2,274 减至 272。
- 八种 3D 角色皮肤共享几何资源，关节变换独立。100 个混合皮肤角色的唯一几何由 416 份降至 36 份；本机重复创建 1,000 个角色约由 5.25 秒降至 0.53 秒。实际收益取决于可见人数、皮肤种类和设备。
- 标签投影复用向量和视口尺寸，避免逐标签读取布局尺寸；标签更新与画面帧率分离，远处角色停止不必要的骨骼动画。
- 店铺目录以 ETag 重新验证，数据不变返回无正文的 304；变更后返回最新资料。前端不重复重建相同目录，页面隐藏时暂停周期性刷新。

## 正确性保护

公共榜单缓存返回副本，调用方补充职位等展示字段不会污染后续请求。缓存通过 SQLite 写计数、外部连接的数据版本和两秒最长寿命失效；周榜切换和经验配置也区分缓存键。管理列表继续实时查询。

`public_cache_test.go` 验证投币、金额、收录、停用、改名、外部写入与调用方修改后的结果；`world_catalog_test.go` 验证目录变更、304 和 gzip 一致性。`web/world/batching.test.js` 验证共享几何、独立关节，以及移除其他角色后资源仍可使用。

```bash
go vet ./...
go test ./... -count=1
go test -race ./... -count=1
npm run test:world
```
